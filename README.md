# 📊 Desafio de Projeto - Relatório Financeiro com Foco em UX/UI

Este repositório contém a atualização do Relatório Financeiro desenvolvido no Power BI, focado em melhorar a experiência do utilizador (UX).

## 🎯 Objetivos do Desafio
- Redesenhar e reestruturar as páginas do relatório promovendo uma melhor hierarquia visual.
- Aplicar princípios de **Posicionamento**, **Contraste**, **Proporção** e **Segmentação dos dados**.
- Adicionar botões de navegação interativos com feedbacks visuais (Hover/Press).

## 🛠️ Principais Alterações Realizadas
- **Substituição de Visual:** Troca do gráfico de radar por um gráfico de barras horizontais para melhorar a leitura dos dados por produto.
- **Design de Cards:** Aplicação de contornos arredondados e fundo branco sobre fundo suave para destacar os gráficos.
- **Limpeza Visual:** Padronização de rótulos de dados e remoção de títulos de eixos desnecessários.
- **Navegação Interativa:** Menus e botões estilizados para alternar fluidamente entre as 3 páginas do relatório.
